# FKB Remote — Full Keyboard Remote

Use seu celular como um Stream Deck improvisado no Windows.
Mapeia teclas especiais (F13-F24 e Virtual Keys) para botões
no app Unified Remote, acionadas via AutoHotkey.

## Componentes
- fkb.exe — motor compilado em AutoHotkey v2
- fkb_streamdeck.py — configurador com interface CLI

## Requisitos
- Windows
- Unified Remote Server instalado
- Python 3.x

## Como usar
1. Baixe e execute fkb_streamdeck.py
2. O programa instala as dependências automaticamente
3. Crie um perfil e adicione suas teclas
4. Abra o Unified Remote no celular e use
